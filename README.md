# Lena Desktop (Windows)

Windows installer for the **Lena** call dashboard — Praxis am Belvedere.

## Download

**[⬇ Lena-Setup.exe (latest)](https://github.com/maximilliangrand/lena-desktop/releases/latest/download/Lena-Setup.exe)**

Run the installer and follow the on-screen steps. See the setup guide PDF you were sent for a full walkthrough.

> The app is an unsigned internal tool. Windows SmartScreen will show a warning on first run — choose **More info → Run anyway**. This is expected.
